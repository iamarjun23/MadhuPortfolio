- Headless screenshots at any viewport: a small Chrome DevTools Protocol script (Node 26 has a global `WebSocket`, so no dependency is needed) that launches `chrome.exe --headless=new --remote-debugging-port=…`, calls `Emulation.setDeviceMetricsOverride`, scrolls, and runs `Page.captureScreenshot`.
